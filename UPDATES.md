# updates

whats new in each version of OG360, newest first. when theres an update OG360 pops up a box with the new stuff from here.

## 1.0.8
area 51 got a free camera. the world freezes and you fly around with your controller, every room shows up and so does the stuff the devs left outside the map, with a light haze so nothing unlit is pitch black. let go of x and it drops you right where the camera is.

theres an update box now that pops up with whats new when theres an update. you can turn it off in tools.

calls can take a ready step now and the how it works doc got cleaned up.

## 1.0.7
area 51 is in now: god mode, unlimited ammo that the game runs itself so nothing gets spammed to the console, all weapons, unlimited grenades, full mutation, slow motion, bullet time, double speed, a level select that loads any level and hands you a gun when you get there, and unlock all lore and secrets.

mortal kombat deception is tested now and got a save your profile button and a free camera that pauses the fight.

calls can go through a games own hook now (mk deception and area 51) and switches can write once instead of every pass.

## 1.0.6
og games cant knock the xbox 360 off the network anymore and connecting doesnt freeze it. OG360 holds the network card itself now with one jrpc2 call instead of patching xams code, so connecting mid game or after quitting a game is fine. no jrpc2 means it does it the old way like before

## 1.0.5
new mods for destroy all humans (god mode, infinite ammo, first person, giant crypto and more), mortal kombat deception and dave mirra freestyle bmx 2. the mk and dave mirra ones arent tested on the console yet. the readme, docs and app say xbox 360 now instead of just 360

## 1.0.4
fixed ebx, ebp and xmm calls in halo 2 taking the gaps halo 2s own hook uses. halo 2s fade_in works through xmm0 now

## 1.0.3
calls can use ebx, ebp and xmm0 to xmm3 now. they go through a new gate that fits itself into whatever game is running, on any xefu, and the games fpu gets saved and put back around those calls

## 1.0.2
fixed the xefu notes in the how it works doc. writing over a games code doesnt do anything under xefu, new code reached through a pointer does

## 1.0.1
added a how it works doc and credits for XeCrippy and py-xbdm
