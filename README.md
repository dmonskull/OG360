# OG360

OG360 is for modding og xbox games while theyre running on the 360 under xefu (the 360s backwards compat emulator). it talks to the console over xbdm so you can flip mods on and off live, change or lock values, search memory, call the games own functions and boot games straight from the hdd.

the memory tools work on any og game. these ones also come with ready made mods:

- halo ce
- halo 2
- mafia
- true crime streets of la
- aggressive inline
- need for speed underground 2
- gauntlet dark legacy (just a few values for now)

more features are planned for the future.
